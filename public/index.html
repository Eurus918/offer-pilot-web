DeepSeek API Key

本产品调用 DeepSeek 大模型。Key 仅保存在你本地 data/store.json，不会上传。获取：platform.deepseek.com API Keys。

当前是在线演示版：为安全起见，这里不保存也不使用访客填写的 Key，AI 能力由部署者统一配置。想用自己的 Key 与真实数据，请把项目 clone 到本地运行。

腾讯会议 API（可选）

配置后可自动拉取会议「元宝纪要」生成复盘，不必手动粘贴。前提：商业版/企业版会议账号，且应用具备「查看企业录制」权限。凭证仅存本地 data/store.json。
